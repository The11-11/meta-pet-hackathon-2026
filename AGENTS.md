# Meta Hackathon workspace

Meta Pet is the app. Muse Pet is its AI companion. Petaverse is the wider ecosystem. Keep these roles distinct in product copy and documentation.

The canonical app and backend are in `apps/meta-pet/`. Use that working directory for app commands and read its `AGENTS.md` before implementation; it contains the Expo version and verification requirements. The original app path is a compatibility junction to this source tree, not a second copy.

Project context is in `docs/`. Keep verified features distinct from concepts, pending integrations and untested device behavior. Retain the original 22 October 2026 development history. Private backend settings stay server-side and excluded from archives and source control.
