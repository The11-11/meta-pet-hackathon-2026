## Try the care journey

1. Choose **Continue with Facebook** and complete your own sign-in.
2. Create a clearly labelled demonstration pet and choose a care goal. Photo generation is optional. If offered an existing demo-profile import, review it explicitly; an existing Facebook profile must remain protected.
3. Open **Start with Muse** and ask for a walk, meal or everyday-care plan. Enter accurate observations for a real pet.
4. Check the actual response label. **MUSE · LIVE MODEL** identifies completed live inference; a local guide is a separate preview.
5. Ask for a local reminder at a time that is still in the future when you test. Review the exact date, time and note before approval; after approval, check one saved appointment note appears.
6. Open **View Muse page memory** and inspect harmless saved context for the selected pet.
7. Sign out of Meta Pet, then sign in with the same Facebook account in the same browser. Verify that profile and saved page memory return.
